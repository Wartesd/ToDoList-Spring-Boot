Небольшой пет-проект списка задач на Spring Boot и Java. Делал для практики работы со Spring Security и построения нормальной серверной логики.  Здесь есть полноценная регистрация и вход, а также разделение по ролям: обычный юзер, админ и суперадмин. Под капотом у каждого пользователя свой личный кабинет со списком дел, статусами задач и возможностью ими управлять. У админов есть отдельные закрытые панели для управления.  Стек классический: Spring Boot, база данных (PostgreSQL через Hibernate), шаблоны на Thymeleaf с базовыми стилями и Maven для сборки. Дополнительно настроил нормальные странички под частые ошибки вроде 403 и 404. Запускается просто: поднять базу, вписать свои логин и пароль в конфиг и стартовать проект.
